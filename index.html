Contador de TO

Guia completo para instalação, configuração e utilização do bot responsável pela busca e envio automático das TOs.

Como funciona?

O Contador de TO utiliza uma extensão no navegador e um script que realiza a leitura das informações no SPX, executa a busca das TOs e envia os dados automaticamente para uma planilha.

1

Instalar o Tampermonkey

Instale a extensão Tampermonkey no Google Chrome. Ela será responsável por executar o script do Contador de TO.

2

Permitir scripts de usuário

Acesse as configurações da extensão no Chrome e habilite a opção que permite a execução de scripts de usuário.

3

Instalar o Script

Abra o painel do Tampermonkey, crie um novo script, cole o código do Contador de TO e salve.

4

Abrir o SPX

Entre no SPX normalmente. Com o script ativo, o painel do bot ficará disponível na página.

5

Buscar as TOs

No SPX TO Report, utilize o botão de busca do bot. O sistema fará a leitura e contabilização das TOs.

6

Enviar para a Planilha

Após a busca, os dados são enviados automaticamente para a base configurada no Google Sheets.
