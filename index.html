Contador de TO

Guia completo para instalar, configurar e utilizar o bot responsável pela busca automática de TOs no SPX e envio dos dados para o Google Sheets.

Como funciona?

O Contador de TO utiliza a extensão Tampermonkey para executar um script diretamente no SPX. Depois de instalado, o bot realiza a busca das TOs, contabiliza os registros e envia as informações automaticamente para a planilha configurada.

1

Baixar o Tampermonkey

O Tampermonkey é a extensão responsável por executar o script do Contador de TO no navegador.

Clique no botão abaixo para abrir a página oficial da extensão na Chrome Web Store.

Download da Extensão
Na Chrome Web Store, clique em Usar no Chrome e depois Adicionar extensão.
2

Permitir Scripts de Usuário

Depois de instalar o Tampermonkey, é necessário liberar a execução de scripts de usuário no Chrome.

  1. Clique no ícone de Extensões no Chrome.
  2. Localize o Tampermonkey.
  3. Clique nos três pontinhos.
  4. Clique em Gerenciar extensão.
  5. Procure a opção Permitir scripts de usuário.
  6. Ative essa opção.
  7. Depois, volte para esta página.
Ative scripts de usuário somente quando você souber a origem e finalidade do script que está instalando.
3

Instalar o Script

Agora que o Tampermonkey está instalado e configurado, você pode instalar o Contador de TO.

Clique no botão abaixo.

Instalar Script
O Tampermonkey deverá abrir automaticamente a tela de instalação do script.

Na tela do Tampermonkey, clique em:

Instalar

4

Abrir o SPX

Depois de instalar o script, acesse o SPX normalmente.

O script foi configurado para funcionar dentro do ambiente SPX.

Se a instalação estiver correta, o botão SPX TO REPORT aparecerá automaticamente na página.
5

Abrir o Bot

Dentro do SPX, localize o botão:

SPX TO REPORT

Clique nele para abrir o painel do Contador de TO.

No painel você poderá visualizar:

  • Data inicial
  • Data final
  • Status da automação
  • Próxima atualização
  • Últimos TOs encontrados
6

Buscar as TOs

Escolha a data inicial e a data final desejada.

Depois clique no botão:

ATUALIZAR AGORA

O bot fará a busca das TOs diretamente no SPX.

Durante a execução, o painel mostrará quantas TOs já foram encontradas.
7

Atualização Automática

O Contador de TO possui automação integrada.

Depois de ativado, o bot realiza novas buscas automaticamente em intervalos definidos pelo sistema.

O painel exibirá:

  • Automação ativa ou pausada
  • Última atualização
  • Próxima execução
  • Tempo restante
8

Envio para Google Sheets

Depois que as TOs forem encontradas, os registros são enviados automaticamente para a planilha configurada.

Quando o envio for concluído, o bot mostrará a mensagem: PLANILHA ATUALIZADA.
9

Exportar CSV

Caso seja necessário utilizar os dados fora da planilha, também é possível exportar as TOs encontradas.

Clique em:

EXPORTAR CSV

O arquivo será gerado diretamente no navegador.
