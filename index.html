Contador de TO

Guia completo para instalar, configurar e utilizar o bot responsável pela busca automática de TOs no SPX.

Como funciona?

O Contador de TO utiliza a extensão Tampermonkey para executar um script dentro do SPX. Depois de instalado, o bot permite realizar a busca das TOs de forma rápida e visualizar os registros encontrados diretamente no painel.

Passo a passo de instalação

Siga cada etapa abaixo na ordem para instalar e utilizar o Contador de TO.

1

Baixar o Tampermonkey

O Tampermonkey é a extensão responsável por executar o script do Contador de TO no navegador.

Clique no botão abaixo para abrir a página oficial da extensão na Chrome Web Store.

Download da Extensão
Na Chrome Web Store, clique em Usar no Chrome e depois em Adicionar extensão.
2

Permitir Scripts de Usuário

Depois de instalar o Tampermonkey, é necessário liberar a execução de scripts de usuário no Chrome.

  1. Clique no ícone de Extensões no Chrome.
  2. Localize o Tampermonkey.
  3. Clique nos três pontinhos.
  4. Clique em Gerenciar extensão.
  5. Procure a opção Permitir scripts de usuário.
  6. Ative essa opção.
  7. Depois, volte para esta página.
Ative scripts de usuário somente quando você souber a origem e a finalidade do script que está instalando.
3

Instalar o Script

Agora que o Tampermonkey está instalado e configurado, você pode instalar o Contador de TO.

Clique no botão abaixo.

Instalar Script
O Tampermonkey deverá abrir automaticamente a tela de instalação do script.

Na tela do Tampermonkey, clique em Instalar.

4

Abrir o SPX

Depois de instalar o script, acesse o SPX normalmente.

Faça login utilizando seu Ops ID ou com o Google.

O script foi configurado para funcionar dentro do ambiente SPX.

Abrir SPX
5

Abrir o Bot e Ativar

Dentro do SPX, abra o Tampermonkey e confirme se o script está ativo.

Quando o script estiver funcionando corretamente, o status deverá aparecer como Ativado.

  • Abra o Tampermonkey.
  • Confirme se aparece o símbolo verde Ativado.
  • Caso esteja desligado, clique para ativar.
  • Volte para o SPX.
  • Localize o botão SPX TO REPORT.
  • Clique nele para abrir o painel do bot.
Com o script ativo, o botão SPX TO REPORT deverá aparecer automaticamente dentro do SPX.
6

Buscar TOs

Com o painel SPX TO REPORT aberto, selecione o período que deseja consultar.

Escolha:

  • Data inicial
  • Data final

Depois clique no botão:

BUSCAR TOs

O bot realizará a consulta e exibirá automaticamente:

  • Status da busca
  • Total de TOs encontradas
  • Últimos TOs encontrados
  • Status de cada TO
  • Quantidade de volumes
Quando aparecer Busca concluída, a consulta foi finalizada com sucesso.

Instalação concluída

Depois de concluir todos os passos, o Contador de TO estará pronto para uso. Sempre que precisar realizar uma consulta, basta acessar o SPX, abrir o SPX TO REPORT e selecionar o período desejado.

Tampermonkey instalado → Scripts liberados → Script instalado → SPX acessado → Bot ativado → Busca de TOs concluída
